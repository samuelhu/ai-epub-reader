Features

Everything you need to read deeper

No distractions. No subscriptions. Just you, your books, and an AI tutor that works.

⚡

One-Click AI

Select a word for an instant dictionary lookup. Select a passage and tap Brief for a distillation or Detailed for vocabulary, style notes, and context.

🔒

100% Private

Books stay in your browser's local storage. AI requests go directly from your browser to the provider. No servers, no telemetry, no accounts.

🔊

Text-to-Speech

Built-in Read Aloud reads any selected passage. After speech ends, a chip lets you jump back to the AI response.

🎨

Read Your Way

Light, Dark, and Sepia themes. Adjustable font size, family, line spacing, and margins. Fullscreen mode. Settings remembered per book.

💸

Fraction-of-a-Cent AI

Powered by DeepSeek at $0.27/M tokens — GPT-4-class quality at ~1/50th the cost. OpenAI, Anthropic, Gemini, and Ollama also supported.

⌨️

Minimal & Fast

Keyboard navigation, EPUB + TXT support, Table of Contents, reading progress per book. No bloat — just a clean reading experience.

How It Works

Start reading in seconds

No sign-up. No command line required for the quick install.

1

Install the Extension

Download the zip, unzip, and load the dist/ folder in Chrome's extension manager.

2

Add Your Books

Drag an EPUB or TXT file into the library. Books are stored locally in your browser.

3

Select Text & Learn

Select any word or passage. The AI tutor explains it instantly. Tap Read Aloud to listen.

4

Set Your AI Key

Paste a DeepSeek API key in Settings. Free to sign up, fractions of a cent per use.

Install

Get the Extension

Two ways to install — pick the one that fits.

📦 Quick Install

  1. Download ai-epub-reader-v1.0.0.zip from Releases
  2. Unzip anywhere on your computer
  3. Go to chrome://extensions, enable Developer mode
  4. Click Load unpacked → select the unzipped dist/ folder

🔧 From Source

git clone https://github.com/samuelhu/ai-epub-reader.git
cd ai-epub-reader
npm install
npm run build

Then load dist/ as an unpacked extension (same as steps 3–4 above).
